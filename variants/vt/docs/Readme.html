VTDeskWidget 使い方

hololive・にじさんじ・あおぎり高校・ぶいすぽっ！・ネオポルテ・ミリプロ・ななしいんく・のりプロなど、複数プロダクションのVTuberタレントの配信状況をタブ切替で常時表示するデスクトップウィジェット

バージョン 1.0.0

※本ツールは個人が制作した非公式のファンメイドアプリです。hololive/hololive production/カバー株式会社、にじさんじ/ANYCOLOR、あおぎり高校、ぶいすぽっ！/Gemdisc、ネオポルテ、その他本アプリが参照する各タレント・プロダクションとは無関係です。

English version →

デスクトップに常時表示される、透過背景のライブ状況ウィジェット。「すべて」タブで全プロダクションのタレントをまとめて確認できる。

主な機能

  • 複数プロダクションをタブで切替: ホロライブ・にじさんじ・あおぎり高校・ぶいすぽっ！・ネオポルテ・ミリプロ・ななしいんく・のりプロ・個人勢のタブに加え、表示中の全タブのタレントをまとめて確認できる「すべて」タブも常に先頭に表示。表示するタブ自体は右上の「表示」ボタンや右クリックメニューから選べる
  • 配信状況の一覧表示: 配信中・待機中・取得エラーを色分けカードで表示。タレントのカードをクリックすると配信ページ(YouTube)を開く
  • 常時前面表示できる半透明ウィジェット(ドラッグで移動・端や角のドラッグでリサイズ)
  • LIVEフィルタ: 配信中のタレントだけに絞り込み、配信タイトルをティッカー表示
  • 世界時計(初期値: ハワイ・ロサンゼルス・ニューヨーク・UTC・中央ヨーロッパ・ドバイ・ジャカルタ・東京の8種類、地域名つき、設定ファイルで変更可)を表示
  • 最前面固定・全画面表示・ダークモード/ライトモード・テーマカラー・フォント・日本語/英語表示をボタンや右クリックメニューから切り替え
  • ウィンドウ位置やお好みの設定を自動保存し、次回起動時に復元

起動方法

VTDeskWidget.exe をダブルクリックするだけで起動します。インストール作業は不要です。

初回起動時にWindows SmartScreenの警告が出る場合は「詳細情報」→「実行」を選んでください(署名されていない実行ファイルのための一般的な警告です)。

動作環境

  • OS: Windows 10 / 11
  • インターネット接続が必要です(配信状況の取得、チャンネルの自動解決に使用します)。
  • Pythonなど追加のインストールは不要です。VTDeskWidget.exe単体で動作します。

画面の見方

タレントごとに配信状況が色分けされたカードで一覧表示されます。

表示意味
配信中現在ライブ配信を実施中
待機中現在は配信していない
エラー状況の取得に失敗(通信状態やYouTube側の変更などが原因)

タレントのカードをクリックすると配信ページ(YouTube)が開きます。右クリックすると、名前や配信タイトルをクリップボードにコピーするメニューが表示されます。

画面上部のタブでプロダクションを切り替えられます。「すべて」タブは表示中の全プロダクションのタレントをまとめて表示する特別なタブです。

ウィンドウの操作

  • 移動: ウィンドウの背景部分をドラッグ
  • サイズ変更: ウィンドウの端・角をドラッグ
  • 背景の濃さ: 下部のスライダーで透過度を調整
  • 文字サイズ: 下部のスライダーで調整

ボタン機能

表示表示するプロダクションタブをチェックリストから選びます
ダーク/ライト(月アイコン)ダークモードとライトモードを切り替えます

右クリックメニュー

ウィジェット上で右クリックすると、上のボタンと同じ設定に加えて「更新」もまとめたメニューが開きます。ボタンが小さくて押しづらい場合はこちらが便利です。タレントの行の上で右クリックすると、名前や配信タイトルをコピーするメニューが表示されます。

表示タレントの追加・編集

右上のタブでホロライブ・にじさんじ・あおぎり高校・ぶいすぽっ！・ネオポルテ・ミリプロ・ななしいんく・のりプロ・個人勢を切り替えられます(「すべて」タブはこれらをまとめて表示する特別なタブです)。実行ファイルと同じフォルダにある productions フォルダの中の各JSONファイル(例: hololive.json)を編集すると、そのタブに表示するタレントを追加・変更できます。自分だけのタレントを追加したい場合は productions/custom.json(個人勢タブ)を編集してください。

世界時計に表示する時刻帯は clock_zones.json を編集することで追加・削除・変更できます。各項目には日本語/英語の地域名(name_ja/name_en)も設定でき、時刻の横に表示されます。各項目に任意で "dst": {"rule": "us", "offset_hours": 1, "label": "EDT"} のような設定を加えると、サマータイム期間中だけ自動でラベルと時刻がずれます(ruleは"us"または"eu")。

{ "name": "名前", "unit": "ユニット名", "slug": "スラッグ", "channel_url": "https://www.youtube.com/..." }

起動時にチャンネルの自動解決を試みるのはホロライブタブのみで、hololive公式サイトのタレントページから解決し、失敗したときだけchannel_url(未指定の場合はhttps://www.youtube.com/@<slug>)にフォールバックします。それ以外のタブは常にchannel_urlをそのまま使うため、正確なURLを指定してください。ホロライブタブでも自動解決が失敗しやすいタレント(卒業済みなど)ではchannel_urlを指定しておくと安定します。編集後はウィジェットを再起動するか、右クリックメニューの「更新」を使ってください。

注意事項

  • 配信中判定はYouTubeの内部API(innertube)経由でチャンネルの「Live」タブを取得する非公式な方法のため、YouTube側の仕様変更で一時的に動作しなくなる場合があります。
  • インターネット接続が必要です。
  • ウィンドウの位置やサイズなどの個人設定は、実行ファイルと同じフォルダの settings.json に自動保存されます。

うまく動かないときは

実行ファイルと同じフォルダに生成される start_widget.log にエラー内容が記録されます。問題が続く場合はこのログを確認してください。
