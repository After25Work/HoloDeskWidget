VTDeskWidget User Guide

A desktop widget that always shows the live status of VTuber talents across multiple productions (hololive, NIJISANJI, Aogiri Highschool, VSPO!, Neo-Porte, Million Production, 774inc, Noripro, and more), switchable by tab.

Version 1.0.0

This is an unofficial, fan-made app created by an individual. It is not affiliated with hololive/hololive production/COVER Corp., NIJISANJI/ANYCOLOR, Aogiri Highschool, VSPO!/Gemdisc, Neo-Porte, or any other talent/agency referenced in this app.

A transparent-background widget that stays on your desktop, showing live status at a glance. The "All" tab combines every enabled production into one list.

Key Features

  • Switch between productions by tab: hololive, NIJISANJI, Aogiri Highschool, VSPO!, Neo-Porte, Million Production, 774inc, Noripro, and Independent, plus an "All" tab (always shown first) that combines every enabled tab's talents into one list. Which tabs are shown can be chosen from the "Show" button or the right-click menu
  • Live-status overview: shows live / idle / fetch-error status as color-coded cards. Click a talent's card to open their stream page (YouTube)
  • Always-on-top, semi-transparent widget (drag the background to move, drag the edges/corners to resize)
  • LIVE filter: narrows the list to only the talents currently live, with a scrolling ticker for stream titles
  • World clock with region names (default: 8 zones — Hawaii, Los Angeles, New York, UTC, Central Europe, Dubai, Jakarta, Tokyo — configurable via a settings file)
  • Toggle always-on-top, fullscreen, dark/light mode, theme color, font, and Japanese/English display from the buttons or right-click menu
  • Window position and preferences are saved automatically and restored on the next launch

Starting the App

Just double-click VTDeskWidget.exe. No installation required.

If Windows SmartScreen shows a warning on first launch, click "More info" → "Run anyway" (this is the standard warning for an unsigned executable).

System Requirements

  • OS: Windows 10 / 11
  • An internet connection is required (used for fetching live status and for channel auto-resolution).
  • No additional installation (such as Python) is required — VTDeskWidget.exe runs standalone.

Reading the Screen

Each talent is shown as a card, color-coded by live status.

IndicatorMeaning
LiveCurrently streaming live
IdleNot currently streaming
ErrorFailed to fetch status (network issue or a YouTube-side change)

Click a talent's card to open their stream page (YouTube). Right-click it to open a menu for copying their name or stream title to the clipboard.

Use the tabs at the top of the widget to switch productions. The "All" tab is a special tab that combines every enabled production's talents into one list.

Moving and Resizing the Window

  • Move: drag the window's background
  • Resize: drag any edge or corner
  • Background opacity: adjust with the slider at the bottom
  • Text size: adjust with the slider at the bottom

Right-Click Menu

Right-clicking anywhere on the widget opens a menu with the same settings as the buttons above, plus "Refresh" — handy if the buttons are too small to hit precisely. Right-clicking on a talent's row opens a menu for copying their name or stream title.

Adding or Editing Talents

Use the tabs at the top to switch between hololive, NIJISANJI, Aogiri Highschool, VSPO!, Neo-Porte, Million Production, 774inc, Noripro, and Independent (the "All" tab is a special tab that combines all of them). Edit the matching JSON file (e.g. hololive.json) inside the productions folder, located next to the executable, to add or change which talents are shown on that tab. To add your own talents without affecting any other production, edit productions/custom.json (the Independent tab).

The world clock's time zones can be added, removed, or changed by editing clock_zones.json. Each entry can also set a Japanese/English region name (name_ja/name_en) shown next to the time. Add an optional "dst": {"rule": "us", "offset_hours": 1, "label": "EDT"}-style entry to any zone to auto-switch its label and time during that zone's summer-time period (rule is "us" or "eu").

{ "name": "Name", "unit": "Unit name", "slug": "slug", "channel_url": "https://www.youtube.com/..." }

Only the hololive tab tries to auto-resolve channels at startup, from the official hololive talent page, falling back to channel_url (or https://www.youtube.com/@<slug> if omitted) only when that fails. Every other tab always uses channel_url as-is, so enter it accurately. Even on the hololive tab, setting channel_url explicitly helps for talents where auto-resolution tends to fail (e.g. graduated talents). After editing, restart the widget or use "Refresh" in the right-click menu.

Notes

  • Live-status detection works by querying YouTube's internal API (innertube) for the channel's "Live" tab — an unofficial method that may stop working temporarily if YouTube changes this API.
  • An internet connection is required.
  • Personal settings such as window position and size are saved automatically to settings.json, in the same folder as the executable.

Troubleshooting

Errors are recorded to start_widget.log, created in the same folder as the executable. Check this log if problems persist.
