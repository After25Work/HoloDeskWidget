HoloDeskWidget User Guide

A desktop widget that always shows the live status of hololive talents.

Version 1.1.0

This is an unofficial, fan-made app created by an individual. It is not affiliated with hololive, hololive production, or COVER Corp.

日本語版 →

A transparent-background widget that stays on your desktop, showing live status at a glance.

Key Features

  • Live-status overview: shows live / idle / fetch-error status as color-coded cards
  • Pause/resume auto-refresh: a button above the refresh button pauses or resumes the 180-second automatic refresh cycle (manual refresh still works while paused)
  • Always-on-top, semi-transparent widget (drag the background to move, drag the edges/corners to resize)
  • LIVE filter: narrows the list to only the talents currently live, with a scrolling ticker for stream titles
  • World clock showing JST/WIB/UTC/EST/PST
  • Toggle always-on-top, dark/light mode, theme color, and Japanese/English display from the buttons or right-click menu
  • Window position and preferences are saved automatically and restored on the next launch

Starting the App

Just double-click HoloDesk Widget.exe. No installation required.

If Windows SmartScreen shows a warning on first launch, click "More info" → "Run anyway" (this is the standard warning for an unsigned executable).

System Requirements

  • OS: Windows 10 / 11
  • An internet connection is required (used for fetching live status and for channel auto-resolution).
  • No additional installation (such as Python) is required — HoloDesk Widget.exe runs standalone.

Reading the Screen

Each talent is shown as a card, color-coded by live status.

IndicatorMeaning
LiveCurrently streaming live
IdleNot currently streaming
ErrorFailed to fetch status (network issue or a YouTube-side change)

Click a talent's card to open their stream page (YouTube). Right-click it to open a menu for copying their name or stream title to the clipboard.

Moving and Resizing the Window

  • Move: drag the window's background
  • Resize: drag any edge or corner
  • Background opacity: adjust with the slider at the bottom
  • Text size: adjust with the slider at the bottom
  • Text width: adjust with the "Width" slider. Widening it gives the talent-name columns more room, so long names that were cut off are spelled out in full
  • Talent name / stream title widths: in the LIVE view (or while filtering by stream title), the "Name" slider sets how much of each row the talent name takes; whatever it doesn't take goes to the stream title beside it
  • Filter by stream title: type in the search box below the sliders and the list narrows as you type, one character at a time (case-insensitive). Ctrl+F jumps to the box; Esc or the × button beside it clears the filter

Right-Click Menu

Right-clicking anywhere on the widget opens a menu with the same settings as the buttons above — handy if the buttons are too small to hit precisely.

Adding or Editing Talents

Edit productions\hololive.json, located in the same folder as the executable, to add or change which talents are shown.

{ "name": "Name", "unit": "Unit name", "slug": "slug", "channel_url": "https://www.youtube.com/..." }

At startup the widget always tries to resolve the channel from the official hololive talent page first, and only falls back to channel_url (or https://www.youtube.com/@<slug> if omitted) when that fails. Setting channel_url explicitly helps for talents where auto-resolution tends to fail (e.g. graduated talents). After editing, restart the widget or use "Refresh" in the right-click menu.

Notes

  • Live-status detection works by querying YouTube's internal API (innertube) for the channel's "Live" tab — an unofficial method that may stop working temporarily if YouTube changes this API.
  • An internet connection is required.
  • Personal settings such as window position and size are saved automatically to settings.json, in the same folder as the executable.

Troubleshooting

Errors are recorded to start_widget.log, created in the same folder as the executable. Check this log if problems persist.
