HoloDeskWidget 使い方

hololive所属タレントの配信状況を常時表示するデスクトップウィジェット

バージョン 1.0.0

※本ツールは個人が制作した非公式のファンメイドアプリです。hololive、hololive production、カバー株式会社とは無関係です。

English version →

デスクトップに常時表示される、透過背景のライブ状況ウィジェット。

起動方法

HoloDesk Widget.exe をダブルクリックするだけで起動します。インストール作業は不要です。

初回起動時にWindows SmartScreenの警告が出る場合は「詳細情報」→「実行」を選んでください(署名されていない実行ファイルのための一般的な警告です)。

画面の見方

タレントごとに配信状況が色分けされたカードで一覧表示されます。

表示意味
配信中現在ライブ配信を実施中
待機中現在は配信していない
エラー状況の取得に失敗(通信状態やYouTube側の変更などが原因)

タレントのカードをクリックすると名前を、配信タイトル部分をクリックするとタイトルをクリップボードにコピーできます。

ウィンドウの操作

  • 移動: ウィンドウの背景部分をドラッグ
  • サイズ変更: ウィンドウの端・角をドラッグ
  • 背景の濃さ: 下部のスライダーで透過度を調整
  • 文字サイズ: 下部のスライダーで調整

右上のボタン

ボタン機能
終了(✕)ウィジェットを終了します
最前面他のウィンドウより常に手前に表示します
言語(日/EN)表示言語を日本語/英語で切り替えます
テーマカラー(●)配色パレットを選択します
ダーク/ライト(月アイコン)ダークモードとライトモードを切り替えます
LIVE配信中のタレントだけに絞り込んで表示します

右クリックメニュー

ウィジェット上で右クリックすると、上のボタンと同じ設定をまとめたメニューが開きます。ボタンが小さくて押しづらい場合はこちらが便利です。

表示タレントの追加・編集

実行ファイルと同じフォルダにある talents.json を編集すると、表示するタレントを追加・変更できます。

{ "name": "名前", "unit": "ユニット名", "slug": "スラッグ", "channel_url": "https://www.youtube.com/..." }

起動時は常にhololive公式サイトのタレントページからチャンネルの自動解決を試み、失敗したときだけchannel_url(未指定の場合はhttps://www.youtube.com/@<slug>)にフォールバックします。自動解決が失敗しやすいタレント(卒業済みなど)ではchannel_urlを指定しておくと安定します。編集後はウィジェットを再起動するか、右クリックメニューの「更新」を使ってください。

注意事項

  • 配信中判定はYouTubeの内部API(innertube)経由でチャンネルの「Live」タブを取得する非公式な方法のため、YouTube側の仕様変更で一時的に動作しなくなる場合があります。
  • インターネット接続が必要です。
  • ウィンドウの位置やサイズなどの個人設定は、実行ファイルと同じフォルダの settings.json に自動保存されます。

うまく動かないときは

実行ファイルと同じフォルダに生成される start_widget.log にエラー内容が記録されます。問題が続く場合はこのログを確認してください。
